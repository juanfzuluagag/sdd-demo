# visual-design

Aplica solo si el requerimiento incluye interfaz. Respeta el sistema visual
existente; si falta, propone en el blueprint una dirección breve de jerarquía,
tipografía, color y espaciado adecuada a usuarios y plataforma.

Define estados vacíos, carga, éxito, error y foco según corresponda. No dependas
solo del color. Usa componentes semánticos y convenciones de accesibilidad de la
plataforma; considera teclado, lectores de pantalla y movimiento reducido.

Valida tamaños y dispositivos definidos en los criterios. Comprueba legibilidad,
contraste, navegación y ausencia de recortes con herramientas del stack. Captura
estados representativos cuando sea posible. Una imagen no prueba accesibilidad.
Si no puedes inspeccionar la interfaz, registra lo pendiente sin declarar éxito.
