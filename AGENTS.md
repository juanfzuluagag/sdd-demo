# Instrucciones para agentes

Trabaja en español. Antes de actuar, lee `.sdd/REGLAS.md`. Para ejecutar el flujo
SDD lee también `.sdd/FLUJO.md` y `.sdd/CONTEXTO.md`.

Esta es una base genérica: no presupongas un producto ni un stack. El requerimiento
del usuario inicia su adaptación. Mantener la plantilla no inicia el desarrollo.

Los perfiles están en `.codex/agents/` y las skills en `.agents/skills/`.
Los documentos del proceso viven en `.sdd/`; el código se ubicará según el proyecto.
